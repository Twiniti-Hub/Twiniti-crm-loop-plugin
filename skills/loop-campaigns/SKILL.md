# Loop segments and campaign drafts

Prefer these MCP tools first:

- `list_segments`
- `get_segment`
- `estimate_segment_size`
- `create_campaign_draft`
- `get_campaign_status`

Campaign **send** is not an MCP tool yet. Stop at draft / status. Do not invent a send call.

Do not query Neon. Do not paste tokens. Board/kanban is user-only.
