# Loop contacts

Prefer these MCP tools first:

- `search_contacts`
- `get_contact`
- `create_contact`
- `upsert_contact`
- `update_contact`
- `get_contact_timeline`

The credential is org- and region-bound. Do not send workspace-id headers. Do not query Neon. Do not paste tokens.

Board/kanban views are user-only in this release.
